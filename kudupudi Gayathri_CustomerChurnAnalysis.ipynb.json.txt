        "\n",
        "# Remove duplicate customer records if any are present.\n",
        "df = df.drop_duplicates(subset=\"customerID\").reset_index(drop=True)\n",
        "\n",
        "# Target encoding.\n",
        "df[\"ChurnFlag\"] = df[\"Churn\"].map({\"No\": 0, \"Yes\": 1})\n",

      "source": [
        "## 6. Feature Engineering\n",
        "\n",
        "The customer ID is an identifier and is excluded from modelling. `Churn` is the target. The remaining demographic, service, contract, and billing variables are used as predictors.\n"
      ]
    },
    {
      "cell_type": "code",
      "execution_count": null,
      "metadata": {},
      "outputs": [],
      "source": [
        "X = df.drop(columns=[\"Churn\", \"ChurnFlag\", \"customerID\"])\n",
        "y = df[\"ChurnFlag\"]\n",
        "\n",
        "categorical_features = X.select_dtypes(include=[\"object\"]).columns.tolist()\n",
        "numeric_features = X.select_dtypes(exclude=[\"object\"]).columns.tolist()\n",
        "\n",
        "print(\"Categorical features:\", categorical_features)\n",
        "print(\"Numeric features:\", numeric_features)\n"
      ]
    },
    {
      "cell_type": "markdown",
      "metadata": {},
      "source": [
        "## 7. Train-Test Split\n",
        "\n",
        "A stratified split is used so the proportion of churned customers remains similar in the training and test sets.\n"
      ]
    },
    {
      "cell_type": "code",
      "execution_count": null,
      "metadata": {},
      "outputs": [],
      "source": [
        "X_train, X_test, y_train, y_test = train_test_split(\n",
        "    X, y,\n",
        "    test_size=0.20,\n",
        "    random_state=RANDOM_STATE,\n",
        "    stratify=y\n",
        ")\n",
        "\n",
        "print(\"Training rows:\", len(X_train))\n",
        "print(\"Test rows:\", len(X_test))\n"
      ]
    },
    {
      "cell_type": "markdown",
      "metadata": {},
      "source": [
        "## 8. Preprocessing Pipeline\n",
        "\n",
        "Categorical variables are one-hot encoded and numeric variables are imputed and standardized. Keeping preprocessing inside a pipeline helps prevent data leakage.\n"
      ]
    },
    {
      "cell_type": "code",
      "execution_count": null,
      "metadata": {},
      "outputs": [],
      "source": [
        "numeric_transformer = Pipeline(steps=[\n",
        "    (\"imputer\", SimpleImputer(strategy=\"median\")),\n",
        "    (\"scaler\", StandardScaler())\n",
        "])\n",
        "\n",
        "categorical_transformer = Pipeline(steps=[\n",
        "    (\"imputer\", SimpleImputer(strategy=\"most_frequent\")),\n",
        "    (\"onehot\", OneHotEncoder(handle_unknown=\"ignore\"))\n",
        "])\n",
        "\n",
        "preprocessor = ColumnTransformer(\n",
        "    transformers=[\n",
        "        (\"num\", numeric_transformer, numeric_features),\n",
        "        (\"cat\", categorical_transformer, categorical_features)\n",
        "    ]\n",
        ")\n"
      ]
    },
    {
      "cell_type": "markdown",
      "metadata": {},
      "source": [
        "## 9. Model Training\n",
        "\n",
        "Two classification models are trained:\n",
        "\n",
        "1. **Logistic Regression** \u2014 a transparent baseline model.\n",
        "2. **Random Forest** \u2014 a nonlinear ensemble model capable of capturing interactions between variables.\n"
      ]
    },
    {
      "cell_type": "code",
      "execution_count": null,
      "metadata": {},
      "outputs": [],
      "source": [
        "models = {\n",
        "    \"Logistic Regression\": LogisticRegression(\n",
        "        max_iter=2000,\n",
        "        class_weight=\"balanced\",\n",
        "        random_state=RANDOM_STATE\n",
        "    ),\n",
        "    \"Random Forest\": RandomForestClassifier(\n",
        "        n_estimators=300,\n",
        "        max_depth=12,\n",
        "        min_samples_leaf=3,\n",
        "        class_weight=\"balanced\",\n",
        "        random_state=RANDOM_STATE,\n",
        "        n_jobs=-1\n",
        "    )\n",
        "}\n",
        "\n",
        "results = []\n",
        "fitted_models = {}\n",
        "\n",
        "for name, model in models.items():\n",
        "    pipe = Pipeline(steps=[\n",
        "        (\"preprocessor\", preprocessor),\n",
        "        (\"model\", model)\n",
        "    ])\n",
        "    pipe.fit(X_train, y_train)\n",
        "\n",
        "    y_pred = pipe.predict(X_test)\n",
        "    y_prob = pipe.predict_proba(X_test)[:, 1]\n",
        "\n",
        "    results.append({\n",
        "        \"Model\": name,\n",
        "        \"Accuracy\": accuracy_score(y_test, y_pred),\n",
        "        \"Precision\": precision_score(y_test, y_pred, zero_division=0),\n",
        "        \"Recall\": recall_score(y_test, y_pred, zero_division=0),\n",
        "        \"F1\": f1_score(y_test, y_pred, zero_division=0),\n",
        "        \"ROC-AUC\": roc_auc_score(y_test, y_prob)\n",
        "    })\n",
        "    fitted_models[name] = pipe\n",
        "\n",
        "results_df = pd.DataFrame(results).sort_values(\"ROC-AUC\", ascending=False)\n",
        "display(results_df.round(4))\n"
      ]
    },
    {
      "cell_type": "markdown",
      "metadata": {},
      "source": [
        "## 10. Detailed Evaluation\n",
        "\n",
        "The model with the highest ROC-AUC in the test set is selected for the remaining analysis. The notebook reports a classification report, confusion matrix, and ROC curve.\n"
      ]
    },
    {
      "cell_type": "code",
      "execution_count": null,
      "metadata": {},
      "outputs": [],
      "source": [
        "best_model_name = results_df.iloc[0][\"Model\"]\n",
        "best_model = fitted_models[best_model_name]\n",
        "\n",
        "best_pred = best_model.predict(X_test)\n",
        "best_prob = best_model.predict_proba(X_test)[:, 1]\n",
        "\n",
        "print(\"Selected model:\", best_model_name)\n",
        "print(\"\\nClassification report:\")\n",
        "print(classification_report(y_test, best_pred, target_names=[\"No Churn\", \"Churn\"]))\n",
        "\n",
        "cm = confusion_matrix(y_test, best_pred)\n",
        "plt.figure(figsize=(5, 4))\n",
        "sns.heatmap(\n",
        "    cm, annot=True, fmt=\"d\", cmap=\"Blues\",\n",
        "    xticklabels=[\"No Churn\", \"Churn\"],\n",
        "    yticklabels=[\"No Churn\", \"Churn\"]\n",
        ")\n",
        "plt.title(f\"Confusion Matrix - {best_model_name}\")\n",
        "plt.xlabel(\"Predicted\")\n",
        "plt.ylabel(\"Actual\")\n",
        "plt.show()\n",
        "\n",
        "RocCurveDisplay.from_predictions(y_test, best_prob)\n",
        "plt.title(f\"ROC Curve - {best_model_name}\")\n",
        "plt.show()\n"
      ]
    },
    {
      "cell_type": "markdown",
      "metadata": {},
      "source": [
        "## 11. Model Interpretation\n",
        "\n",
        "For the logistic regression model, coefficients can be inspected after one-hot encoding. Positive coefficients indicate features associated with higher predicted churn probability, while negative coefficients indicate lower predicted churn probability within the fitted model.\n",
        "\n",
        "For the Random Forest model, feature importance is calculated from the fitted tree ensemble.\n"

        "lr_model = lr_pipe.named_steps[\"model\"]\n",

        "feature_names = lr_preprocessor.get_feature_names_out()\n",

        "rf_pipe = fitted_models[\"Random Forest\"]\n",
        "rf_preprocessor = rf_pipe.named_steps[\"preprocessor\"]\n",
        "rf_model = rf_pipe.named_steps[\"model\"]\n",
        "\n",
        "rf_features = rf_preprocessor.get_feature_names_out()\n",
        "rf_importance = pd.Series(rf_model.feature_importances_, index=rf_features).sort_values(ascending=False)\n",
        "\n",
        "plt.figure(figsize=(9, 6))\n",
        "rf_importance.head(15).sort_values().plot(kind=\"barh\")\n",

        "## 12. Customer Risk Scoring\n",
        "\n",
        "The selected model is used to calculate a churn probability for every customer. Customers are then grouped into simple risk bands for analytical prioritization.\n",
        "\n",
        "These risk bands are **not causal conclusions** and should not be treated as proof that a customer will churn.\n"
      ]
    },
    {
      "cell_type": "code",
      "execution_count": null,
      "metadata": {},
      "outputs": [],
      "source": [
        "all_features = df.drop(columns=[\"Churn\", \"ChurnFlag\", \"customerID\"])\n",
        "all_prob = best_model.predict_proba(all_features)[:, 1]\n",
        "\n",
        "risk_output = df[[\"customerID\", \"Contract\", \"tenure\", \"MonthlyCharges\", \"Churn\"]].copy()\n",
        "risk_output[\"ChurnProbability\"] = all_prob\n",
        "risk_output[\"RiskBand\"] = pd.cut(\n",
        "    risk_output[\"ChurnProbability\"],\n",
        "    bins=[-np.inf, 0.30, 0.60, np.inf],\n",
        "    labels=[\"Low\", \"Medium\", \"High\"]\n",
        ")\n",
        "\n",
        "risk_output = risk_output.sort_values(\"ChurnProbability\", ascending=False)\n",
        "\n",
        "display(risk_output.head(20))\n",
        "\n",
        "risk_output.to_csv(\"customer_churn_risk_predictions.csv\", index=False)\n",
        "print(\"Saved: customer_churn_risk_predictions.csv\")\n"
